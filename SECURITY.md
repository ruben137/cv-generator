# Security policy

Security fixes are applied to the latest version on the `main` branch.

## Reporting a vulnerability

Do not disclose suspected vulnerabilities in a public issue. Use GitHub's private vulnerability reporting feature in the repository's **Security** tab. If it is unavailable, contact the maintainer privately through the contact method listed on their GitHub profile.

Include a description, reproduction steps, potential impact, a minimal proof of concept when safe, and any suggested mitigation.

Do not include real CVs, photographs, personal information, credentials, or data belonging to another person. Allow reasonable time for investigation before public disclosure.

Reports involving unexpected transmission, exposure of browser-local CVs, unsafe document generation, dependency compromise, cross-site scripting, or injection are particularly important.
